# Better Flow — Astro Website

Static landing site for Better Flow, migrated from Next.js to Astro 5 for better static-site performance and SEO.

## Stack

- **Framework**: Astro 5
- **UI**: React 19 islands
- **Styling**: Tailwind CSS v4
- **Animation**: Framer Motion, GSAP, Lenis
- **Particles**: @tsparticles/react + @tsparticles/slim
- **Icons**: lucide-react, react-icons

## Commands

```bash
pnpm install
pnpm dev       # start dev server
pnpm build     # static build
pnpm preview   # preview production build
```

## Structure

- `src/pages/` — Astro routes
- `src/app/` — React components & sections (migrated from Next.js)
- `src/layouts/Layout.astro` — SEO-optimized root layout
- `src/styles/globals.css` — Tailwind + custom styles
- `public/` — static assets, robots.txt, llms.txt, manifest.json

## SEO

- Canonical URLs, Open Graph, Twitter Cards
- JSON-LD schema (Organization, WebSite, SoftwareApplication)
- `robots.txt` with AI-crawler allow rules
- `sitemap-index.xml` generated by `@astrojs/sitemap`
- `llms.txt` for AI assistant context

## Environment Variables

Copy `.env.example` to `.env` and fill in optional analytics keys.

## Deploy

Configured for Vercel via `vercel.json` (region `iad1`).
