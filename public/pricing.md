## Features Included (All Free)

- Browser mockups: Safari, Chrome, Arc, Polaroid, Glass, Outline frames
- 3D transforms: Perspective, rotation, depth shadows
- Animations: 20+ presets, timeline editor
- Backgrounds: 100+ gradients, solids, blur, noise, mesh patterns
- Export formats: PNG, JPG (up to 5x / 4K scale), MP4, WebM, GIF
- Video export: FFmpeg WASM, WebCodecs, MediaRecorder
- Local processing: No uploads, no server roundtrips, zero telemetry
- Chrome Extension: Screen recording (in development)
